Telecom fraud has rapidly become a major problem within the telecommunications industry, costing companies billions of dollars annually all around the globe from dangerous scams such as: SIMBox,
Subscription fraud, IRSF...

With the rise of technology and various sophisticated schemes, detecting these types of fraud using basic rule-based systems has become more challenging. Therefore, we propose building a Machine Learning (ML) model that successfully detects these types of fraud more efficiently using algorithms such as XGBoost and Random Forest to prevent further security breaches and minimize financial losses.
The provided solution is expected to improve detection accuracy while reducing false positives comparedto rule-based systems.
